# Running the Project

## Prerequisites

- Python 3.10 or higher
- Install dependencies from requirements.txt

## Setup and Run

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Start the FastAPI server:
   ```bash
   uvicorn main:app --reload
   ```

3. Open your browser and go to [http://localhost:8000/docs](http://localhost:8000/docs) for the API documentation.

## Running Tests

To run the tests:
```bash
pytest
```
